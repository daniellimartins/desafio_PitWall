# 🏎️ PITWALL – GP de São Paulo

Projeto desenvolvido com **HTML5 e CSS3**, inspirado no universo da Fórmula 1 e no Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

O objetivo é criar uma página moderna e responsiva, simulando um site de informações sobre a corrida, com cards de pilotos, classificação, informações das equipes e formulário de ingressos.

## 🎯 Objetivo do Projeto

Praticar os principais conceitos de HTML e CSS, trabalhando com organização de conteúdo, layouts modernos, responsividade e estilização de elementos.

## 🚀 Tecnologias Utilizadas

- **HTML5:** estruturação semântica da página.
- **CSS3:** estilização e organização dos elementos.
- **Google Fonts:** utilização da fonte Titillium Web.
- **Flexbox:** organização dos elementos no layout.
- **CSS Grid:** criação de grades responsivas.
- **Media Queries:** adaptação para dispositivos móveis.

## 🏁 Funcionalidades e Recursos

- **Cabeçalho (Header):** logotipo PITWALL, menu de navegação e botão de compra de ingressos.
- **Seção Hero:** apresentação do GP de São Paulo, imagem de fundo e informações do circuito.
- **Grid de Pilotos:** cards com nomes, números e equipes dos pilotos.
- **Classificação:** tabela organizada com posições, equipes, vitórias, diferenças e pontuação.
- **Filtros:** campos para buscar pilotos e selecionar equipes.
- **Ingressos:** apresentação dos setores disponíveis e seus respectivos valores.
- **Formulário:** campos para preenchimento de dados pessoais, escolha de setor, data, quantidade de ingressos, envio de foto e mensagem para o piloto.
- **Rodapé (Footer):** identificação do projeto e autoria.

## 🎨 Recursos de CSS Aplicados

- `:root` para criação de variáveis de cores e identidade visual das equipes.
- `display: flex` para organização do cabeçalho, seção principal e filtros.
- `display: grid` com `auto-fit` para distribuição dos cards dos pilotos.
- `grid-template-columns` para organização do formulário.
- `thead` e `tbody` para estruturar a tabela de classificação.
- `@media` para adaptar o layout a diferentes tamanhos de tela.
- `linear-gradient` para criação de efeitos visuais.
- `transition` e `:hover` para adicionar interatividade visual.
- Imagem de fundo e detalhes inspirados na zebra da pista.

## 📱 Responsividade

O projeto utiliza Media Queries para adaptar sua apresentação em dispositivos menores, ajustando:

- Cabeçalho e botões.
- Tamanho dos títulos e textos.
- Cards dos pilotos.
- Filtros de classificação.
- Tabela com rolagem horizontal.
- Formulário de ingressos.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta `pit-wall`.
3. Verifique se a imagem `piloto.jpg` está dentro da pasta `img`.
4. Abra o arquivo `index.html` em seu navegador.
5. Explore as seções da página.
